# Groq AI CLI Assistant

Консольное приложение на Python для взаимодействия с языковыми моделями через API Groq с автоматическим сохранением истории диалогов.

## 🚀 Возможности
- Отправка пользовательских запросов к нейросети Groq (llama-3.3-70b-versatile).
- Получение и вывод ответов прямо в консоль.
- Логирование истории диалогов в текстовый файл history.txt с фиксацией даты и времени.
- Обработка ошибок сети и API без аварийного завершения программы.

## 🛠 Технологии
- Python 3.8+
- Groq API
- Встроенные библиотеки Python: urllib.request, json, datetime.

# AI CLI Assistant

A console Python application for interacting with language models via the Groq API with automatic conversation history saving.

## 🚀 Features

* Sending user prompts to the Groq neural network (llama-3.3-70b-versatile).
* Receiving and outputting responses directly in the console.
* Logging dialogue history into a history.txt text file with date and time stamps.
* Handling network and API errors without crashing the program.

## 🛠️ Technologies

* Python 3.8+
* Groq API
* Built-in Python libraries: urllib.request, json, datetime.
